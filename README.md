```
portfolio/
├── cv.html       # Main HTML structure

```

---

## 🚀 Getting Started

No build tools or installs needed. Just open it in a browser:

1. Clone or download the repository
2. Make sure `cv.html` and `style.css` are in the same folder
3. Open `cv.html` in any modern browser

---

## ✨ Features

- 4 collapsible rows — Who Am I, Projects, Links, Contact
- CRT scanline + flicker animation
- Animated boot sequence on load
- Fully responsive for mobile
- Zero dependencies
